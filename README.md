# 🏫 G.L.I.E.R Public School — Official Website

A modern, responsive, and user-friendly school website developed for **G.L.I.E.R Public School, Makol**. The project focuses on providing an informative and accessible digital platform for students, parents, teachers, and visitors.

---

## 🌐 Live Demo

**GitHub Repository:** https://github.com/krishsharma06666/GLIER.git

---

## 📌 Features

- 📱 Fully responsive design
- 🏠 Attractive home page
- ℹ️ About school section
- 🎓 Academics information
- 🖼️ Gallery section
- 📢 Notices & announcements
- 📞 Contact information
- 🚀 Fast loading and easy navigation

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Tailwind CSS**
